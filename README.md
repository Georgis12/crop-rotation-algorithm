# Algorithme de Rotation des Cultures - Sanctuaires Mirazur

Algorithme développé en Python pour optimiser la rotation des cultures 
sur 21 terrasses en agriculture biodynamique.

## Résultats
- 96,9% de taux d'occupation du sol
- 56 espèces cultivées sur 4 ans de simulation
- 3 177 implantations de cultures planifiées

## Fonctionnalités
- Système de filtres d'éligibilité agronomique
- Notation multicritères (cycle biodynamique, compatibilité, effets sur le sol)
- Génération automatique de diagrammes de Gantt (HTML interactif + PDF)


Réalisé dans le cadre d'un stage aux Sanctuaires du Mirazur (2026).
